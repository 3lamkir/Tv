# Remote Remap — MVP

Приложение для Android TV (тестировалось для Xiaomi TV): назначает кнопкам пульта запуск
выбранного приложения. Перехват работает глобально, пока включён AccessibilityService.

## Как собрать

1. Открыть папку `RemoteRemap` в Android Studio (сама сгенерирует gradle wrapper).
2. Подключить приставку: `adb connect <IP_приставки>:5555` (или через USB, если поддерживается).
3. Run -> выбрать устройство.

## Как использовать

1. После установки открыть приложение на приставке.
2. Нажать **"Открыть настройки Специальных возможностей"** и вручную включить
   `Remote Remap` в списке — система не разрешает включать accessibility-сервисы
   автоматически, это шаг, который обязательно делает пользователь один раз.
3. Вернуться в приложение, нажать **"Добавить сопоставление"**, нажать нужную
   кнопку на пульте — приложение покажет её код и предложит список установленных
   приложений для назначения.
4. Теперь эта кнопка должна запускать выбранное приложение из любого места в системе.

## Если кнопка не перехватывается

Кнопка Home перехвачена не будет почти никогда — так устроена система.

Если не перехватывается что-то ещё (актуально для нестандартных кнопок Xiaomi-пульта,
например кнопки ассистента) — сначала нужно узнать её реальный keyCode:

```
adb shell
getevent -l
```

Нажать кнопку на пульте и посмотреть код события в выводе. Либо через logcat,
отфильтровав по `KeyEvent`, пока смотришь на экран "Поймана кнопка: код ..." в
приложении — если MainActivity открыта на переднем плане, `onKeyDown` покажет код
даже для кнопок, которые не долетают до accessibility-сервиса в фоне (это отдельная
проблема, если так — обсудим доработку отдельно).

## Известные ограничения MVP

- Хранение — простой `SharedPreferences` (keyCode -> packageName), без экрана
  редактирования иконок/названий.
- Действие только одно: запуск приложения. Открытие URL, эмуляция другой клавиши
  и т.п. — следующий шаг, если понадобится.
- `QUERY_ALL_PACKAGES` в манифесте нужен для полного списка приложений; на части
  сборок MIUI Google может ограничивать его — если список пустой, надо разбираться
  отдельно с логами конкретного устройства.
